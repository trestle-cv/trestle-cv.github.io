Configuration

Trestle validates configuration before listening. Command-line flags override environment variables, which override conservative defaults.

Current settings

FlagEnvironmentDefault
--listenTRESTLE_LISTEN127.0.0.1:8090
--data-dirTRESTLE_DATA_DIR./data
--shutdown-timeoutTRESTLE_SHUTDOWN_TIMEOUT10s
--log-levelTRESTLE_LOG_LEVELinfo

Listen safely

The default binds loopback. Trestle requires an explicit host and rejects port zero. Internet-facing deployment and trusted-proxy behavior are not supported yet; keep the service private during development.

Shutdown

SIGINT and SIGTERM remove readiness, stop accepting new work, and allow in-flight requests to finish within the configured timeout.

Trestle is being built in the open.
