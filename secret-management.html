Credentials

Secret management

Trestle displays bearer secrets exactly once and stores only SHA-256 hashes.

  • Use one credential per workload and environment.
  • Grant the smallest scope set.
  • Set an expiry where operationally practical.
  • Rotate by creating a replacement, deploying it, then revoking the old ID.
  • Never place secrets in source, URLs, logs or browser bundles.

Lists expose metadata, scopes, expiry, revocation and last use—but never the secret.

Trestle is being built in the open.
