First-run administration

A fresh Trestle database opens one race-safe setup path for creating its first administrator. There is no default password or permanent setup credential.

Bootstrap flow

  1. Start Trestle on its default loopback address.
  2. Open the dashboard from the same machine.
  3. Enter a valid email and a password of at least 7 characters.
  4. Trestle hashes the password with Argon2id and commits the administrator.
  5. The setup path closes immediately and returns a rotated server-side session.

Race behavior

Setup checks and insertion occur inside one database transaction with a unique identity constraint. A competing request receives 409 setup_complete; it cannot create another first administrator.

Exposure boundary

Keep first-run setup on loopback or a private connection. Supported reverse-proxy and TLS deployment guidance arrives at CP22.

Trestle is being built in the open.
