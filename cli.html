Command-line administration

trestle setup --email-file /run/secrets/admin-email --password-file /run/secrets/admin-password
trestle config show --json
sudo trestle reset --auth --confirm "TRESTLE AUTH"
sudo trestle reset --all --confirm "TRESTLE ALL"

Stop Trestle before reset. A managed installation automatically uses its recorded data directory, normally /var/lib/trestle, and retains a timestamped backup. For development, pass --data-dir /path/to/data or set TRESTLE_DATA_DIR. PostgreSQL reset fails closed.
