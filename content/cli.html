Operations

Command-line administration

Trestle supports headless setup and machine-readable inspection for agents and deployment scripts.

trestle setup --email-file /run/secrets/admin-email --password-file /run/secrets/admin-password --registration-policy closed
trestle config show --json
trestle service status
sudo trestle reset --auth --confirm "TRESTLE AUTH"
sudo trestle reset --all --confirm "TRESTLE ALL"

Stop the service first. Reset automatically targets the data directory recorded by a managed Trestle service, normally /var/lib/trestle, and retains a timestamped backup. For a development instance without an installed service, pass --data-dir /path/to/data or set TRESTLE_DATA_DIR. Reset currently operates on SQLite deployments; PostgreSQL deliberately fails closed so an external database cannot be partially reset. Use the existing backup, restore and migrate commands for database automation.
