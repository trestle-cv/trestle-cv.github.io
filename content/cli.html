Operations

Command-line administration

Trestle supports headless setup and machine-readable inspection for agents and deployment scripts.

trestle setup --email-file /run/secrets/admin-email --password-file /run/secrets/admin-password --registration-policy closed
trestle config show --json
trestle service status
trestle reset --auth --confirm "TRESTLE AUTH"
trestle reset --all --confirm "TRESTLE ALL"

Stop the service first. Reset commands retain timestamped backups and currently operate on SQLite deployments; PostgreSQL deliberately fails closed so an external database cannot be partially reset. Use the existing backup, restore and migrate commands for database automation.
