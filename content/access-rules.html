Collection access rules

Every collection can define separate list, view, create, update and delete rules. Missing rules deny access.

Administrators bypass application rules through their separately protected administration routes. Application users present 15-minute access tokens. Service credentials require both their credential scope and the collection rule.

Denied individual lookups return the same not-found shape as missing records to avoid leaking existence.
