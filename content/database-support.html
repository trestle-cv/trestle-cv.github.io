What parity means

Trestle tests observable HTTP behavior rather than pretending the engines are internally identical. Errors, ordering, null handling, uniqueness, timestamps, JSON, optimistic versions, atomic batches, events and jobs form the frozen parity corpus.

Known engine differences

SQLite uses one owned connection, WAL, STRICT tables and PRAGMA-backed operations. PostgreSQL needs numbered parameters, explicit types, pool limits, transactional migration locking, different sequence behavior and provider-specific job claiming. Those differences stay behind the store boundary rather than leaking into application APIs.

PG00 complete: the SQL surface is classified
