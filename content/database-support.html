Database support

One API contract, evidence per provider.

What parity means

Trestle tests observable HTTP behavior rather than pretending the engines are internally identical. Errors, ordering, null handling, uniqueness, timestamps, JSON, optimistic versions, atomic batches, events and jobs form the frozen parity corpus.

Current experimental boundary

PG03 validates and persists a PostgreSQL connection and initializes all 13 logical system migrations; the PG03R repair made migration history authoritative and enforced the connection timeout. PG04 added provider-parameterized identity parity with exactly one winner for competing first-admin setup. PG05 adds collection metadata and physical schema parity: every field type maps to reviewed provider DDL, rename and additive changes preserve stable columns, and incompatible schema changes leave old metadata and rows intact on both engines. It does not claim that records, querying, files or automation are PostgreSQL-ready yet.

Do not move production data yet

The browser selector intentionally describes PostgreSQL as experimental. SQLite remains the recommended setup choice until PG11 closes the whole product matrix.
