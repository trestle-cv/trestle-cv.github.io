Convenient browser access

my.trestle.cv is a memorable shortcut to your Trestle dashboard. Use it instead of remembering port 7333 or manually typing a localhost address and port.

Set the destination once

  1. Open my.trestle.cv?config.
  2. Keep the defaults for local Trestle, or enter the domain or IP address and port of a remote instance.
  3. Select Save, then Open.

Future visits to my.trestle.cv forward to that saved address.

Saved per browser

The destination is kept in local browser storage. Each browser, profile, or device can point at a different Trestle instance. Return to the ?config URL whenever its address changes.

Local default

http://localhost:7333

The shortcut performs browser navigation only; it is not a reverse proxy and does not expose an instance by itself. Follow the deployment and HTTPS guidance before making Trestle remotely reachable.
