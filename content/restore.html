Restore safely

Trestle validates backup archives online but deliberately refuses to replace its live database.

Preflight

Upload an archive from the Backups dashboard. Trestle verifies the archive format, path safety, database presence and schema compatibility without changing application state.

POST /admin/v1/restores/preflight

Offline restore procedure

  1. Stop Trestle and confirm the process has exited.
  2. Preserve the current data directory as a rollback copy.
  3. Extract the validated archive into a new owner-only directory.
  4. Restore provider-managed S3 objects separately when applicable.
  5. Start Trestle against the restored directory and verify health, schema and representative files.
  6. Revoke restored sessions when moving an archive between hosts or trust boundaries.

Never overwrite trestle.db while Trestle is running.
