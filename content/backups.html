Consistent backups

The administration dashboard creates downloadable archives containing a consistent SQLite snapshot, a manifest and local file objects when local storage is active.

Archive contents

  • manifest.json records format, schema version, storage provider and secret treatment.
  • trestle.db is produced with SQLite VACUUM INTO, rather than copying a live WAL database.
  • files/ is included for local storage. S3 objects remain in the configured bucket and require the provider's own backup policy.

Operational boundary

Backup archives contain sensitive account hashes, sessions and encrypted integration secrets. Store them as production credentials, restrict access and test restore procedures regularly.

Administration API

POST /admin/v1/backups
GET  /admin/v1/backups
GET  /admin/v1/backups/{archive}

All endpoints require an authenticated administrator; mutations also require CSRF protection.
