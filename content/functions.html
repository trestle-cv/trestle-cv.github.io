Functions

Invoke isolated services from committed events.

The first functions feature will dispatch versioned events to AWS Lambda through a provider-neutral job boundary.

  1. The application transaction changes state.
  2. The same transaction records its event and outbox job.
  3. A worker claims the committed job with a lease.
  4. The provider adapter invokes Lambda asynchronously.
  5. Trestle records acceptance, attempts and safe diagnostics.

At least once, deliberately

Events receive stable IDs and idempotency keys. Handlers must tolerate retries. Provider acceptance is not misrepresented as handler completion.

No in-process user code

A local runtime is deferred until it has a separate worker process, resource limits, capabilities, secret scoping, cancellation and credible platform isolation.
