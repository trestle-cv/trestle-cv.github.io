Files

Local storage

Objects live beneath Trestle's private data directory in files/; incomplete objects use files/.staging/.

Storage keys are cryptographically random and contain no client-controlled path segments. Downloads use database lookup followed by a regular-file check. Symlinks, directories and missing objects are refused.

Keep the database and files directory together in backups. S3-compatible storage arrives in CP13.
