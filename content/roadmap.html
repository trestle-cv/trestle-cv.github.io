Roadmap

Build evidence, then change the label.

Trestle is delivered as ordered vertical checkpoints. Each includes implementation, dashboard UX, public documentation and verification.

CP00–06 complete

Foundation and schema

Contracts, lifecycle, SQLite, embedded dashboard, administration and physical collections are implemented and tested.

CP07–11 complete

Data and identity

Versioned records, typed querying, application auth, scoped service identities and collection rules are active.

CP12–18 complete

Files and events

Local and S3-compatible storage, durable realtime, audit, jobs, signed webhooks and AWS Lambda delivery are implemented.

CP19–20 complete · CP21–23 planned

Release

OpenAPI, reference clients, backup and recovery are implemented. Dogfood, deployment and final hardening remain.

No supported public release is available.
