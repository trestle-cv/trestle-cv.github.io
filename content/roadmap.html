Roadmap

Build evidence, then change the label.

Trestle is delivered as ordered vertical checkpoints. Each includes implementation, dashboard UX, public documentation and verification.

CP00–03

Foundation

Contracts, lifecycle, SQLite, embedded frontend and fixed-viewport dashboard.

CP04–11

Data and identity

Administration, collections, records, querying, application auth, service accounts and rules.

CP12–18

Files and events

Object storage, realtime, audit, durable jobs, webhooks and AWS Lambda.

CP19–23

Release

OpenAPI, developer experience, backup/import, dogfood, deployment and hardening.

Status: CP00 implementation in progress. No public release is available.
