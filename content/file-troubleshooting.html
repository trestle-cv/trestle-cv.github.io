File troubleshooting

Upload rejected

Check the 10 MiB object limit, 100 MiB quota, credential scope and multipart field name file.

Metadata exists but bytes do not

Inspect filesystem ownership and restore the database and file tree from the same backup point.

Orphans

The administrator cleanup action removes untracked objects and staging files older than one hour. It never follows client paths or deletes a storage key still referenced by metadata.
