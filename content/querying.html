Querying records

Record lists combine bounded filters, sorting, projection and deterministic cursor pagination through ordinary URL parameters.

GET /api/v1/collections/issues/records
  ?filter=status%20%3D%20%22open%22%20%26%26%20score%20%3E%3D%203
  &sort=-updatedAt
  &fields=title,status,score
  &limit=50

The dashboard exposes the same filter and sort contract and can copy the generated HTTP request. Query text is stored only in the browser for convenience.
