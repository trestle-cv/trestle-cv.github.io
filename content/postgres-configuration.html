Precedence

  1. Command-line database flags
  2. Database environment variables
  3. Owner-only first-run bootstrap state
  4. SQLite defaults

An explicit startup provider makes the browser choice read-only. Provider switching after an administrator is committed will require the later offline migration workflow.

TLS and secrets

Remote PostgreSQL URLs must use TLS. sslmode=disable is accepted only for loopback development. URLs are treated as secrets, redacted from surfaced errors, and never returned by diagnostics.

TRESTLE_DATABASE_PROVIDER=postgres
TRESTLE_DATABASE_URL='postgres://trestle:secret@db.internal/trestle?sslmode=verify-full'
Not yet selectable
