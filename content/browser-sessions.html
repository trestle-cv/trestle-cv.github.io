Authentication

Browser sessions

A browser client keeps its refresh token in appropriately protected application storage and rotates it through the refresh endpoint.

const response = await fetch("/api/v1/auth/refresh", {
  method: "POST",
  headers: {"Content-Type": "application/json"},
  body: JSON.stringify({refreshToken})
});

Concurrent refresh attempts cannot both win. The first transaction revokes the old session and creates its replacement; later attempts receive the same generic invalid-refresh response.
