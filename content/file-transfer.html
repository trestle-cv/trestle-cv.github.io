Files

Upload and download

curl -X POST http://127.0.0.1:8090/api/v1/files \
  -H "Authorization: Bearer $TRESTLE_TOKEN" \
  -F file=@report.pdf \
  -F collection=documents \
  -F recordId=rec_example

Downloads support standard HTTP byte ranges through Range and return 206 Partial Content. Responses set the stored media type, disable MIME sniffing and use a safe fixed content-disposition filename.
