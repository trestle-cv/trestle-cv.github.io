Trusted backends

Any language that can send HTTP can use a scoped service credential.

curl -H "Authorization: Bearer $TRESTLE_TOKEN" \
  http://127.0.0.1:8090/api/v1/collections/issues/records

Bearer identities do not use administrator cookies or CSRF tokens. Every use is scope checked, updates last-used metadata and records attributable audit activity.
