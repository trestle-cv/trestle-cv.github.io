Authentication

Mobile and native clients

The authentication contract is plain JSON over HTTPS and does not require a Trestle SDK.

Store refresh tokens in the platform secure credential store, never logs or ordinary preferences. Treat rotation as an atomic replacement: persist the new token before discarding the response, and never reuse the previous token.

CP09 returns refresh credentials only. Short-lived access credentials become useful when collection access rules are activated in CP11.
