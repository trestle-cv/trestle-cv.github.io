Product definition · not yet released

Your application backend, on foundations you can inspect.

Trestle is a planned open-source, self-hosted backend for collections, authentication, files, realtime events and automation—one Go service, SQLite first, and a language-neutral HTTP API.

Explore the productFollow the build
Portable

Any language

HTTP, JSON and Server-Sent Events are the product contract. SDKs will be conveniences, never privileged gateways.

Understandable

SQLite first

A deliberately single-node starting point keeps transactions, backup, failure and ownership legible.

Self-contained

One executable

The Nift-built administration interface will ship embedded in the Go binary, with no runtime frontend toolchain.

Direction

Product parity where it helps. A Trestle contract everywhere.

Trestle takes inspiration from compact application backends without copying PocketBase APIs, migrations, filters or UI. A future importer may translate data; compatibility is not the architecture.
