Files

Trestle stores uploaded bytes locally behind generated keys while keeping user filenames strictly as metadata.

Uploads are staged with private permissions, hashed while streaming, atomically renamed, then bound to database metadata. A failed metadata transaction removes the staged object.

POST   /api/v1/files
GET    /api/v1/files/:id
DELETE /api/v1/files/:id
