CP05 · Implemented metadata

Schema design

Collection and field names are stable API identifiers, not display labels or SQL fragments.

Naming

Names begin with a lowercase ASCII letter, contain only lowercase letters, digits and underscores, and are at most 63 characters. Leading underscores and reserved names such as admin, api, system and trestle are rejected.

Metadata transactions

A collection and all its fields commit together. Updates replace the ordered field definition inside the same transaction; conflicts or invalid fields leave the earlier schema intact.

Plan before physical data

CP06 will preview effects and require explicit acknowledgement for destructive changes. Until then, metadata is deliberately pre-record and may change without a stable migration guarantee.
