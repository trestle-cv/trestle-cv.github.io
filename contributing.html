Contributing

Small checkpoints. Explicit evidence.

Trestle is being designed around human-directed agentic engineering: define contracts, implement coherent slices, attack failure modes, and preserve an auditable handover.

Before contributing

  1. Read the repository handover and task-relevant contracts in full.
  2. Inspect status and preserve unrelated work.
  3. Identify the user-visible contract and failure behavior.
  4. Define verification before broad implementation.

Current state

The public contribution workflow and code of conduct have not yet been finalized.

Trestle is being built in the open.
